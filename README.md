# INDIAN KITCHEN

A polished restaurant website and local food ordering prototype, built with React, Vite, React Router, Framer Motion and Lucide icons.

## Run locally

1. Open this folder in VS Code.
2. In a terminal, run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.

The menu contains 100 dishes across eight categories. Cart contents, table selection, orders, and admin menu edits are stored in the browser's local storage. Orders can be updated from `/admin` and tracked from `/track`.

## Routes

- `/` — restaurant home
- `/menu` — search, filters, dish details and add to bag
- `/cart` — table selection and checkout
- `/track` — look up orders by their order ID
- `/about` and `/contact` — restaurant information and contact form
- `/admin` — local order, menu and table management

Food photography is loaded from Unsplash, so images need an internet connection. Orders and menu edits are a local demo and are not shared between browsers or devices.
